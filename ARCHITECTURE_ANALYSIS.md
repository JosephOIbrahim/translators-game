## Gap Analysis

### Problem 1: Non-Determinism in Profile Generation

**Current behavior**: Visual elements use `Math.random()` throughout:
- Seed positions, types, spawn counts
- Plant heights, leaf counts
- Creature behaviors
- Garden metrics in visual signature

**Impact**: Garden metrics bleed into profile:
```javascript
profile.visualSignature = {
  seedsPlanted: this.plantedSeeds.length,  // Random!
  plantsGrown: this.plants.length,          // Random!
  energy: Math.min(1, (this.plants.length * 0.1 + ...))  // Random!
};
```

**The Fix**: Separate DETERMINISTIC TRAITS from AESTHETIC VARIATION

```
Answers (deterministic) → Trait Engine (pure functions) → Profile (immutable)
                                    ↓
                              Garden Renderer (can vary)
```

**Trait computation MUST be pure**:
```javascript
// BAD: Current approach mixes randomness
traits[dim].value = avg;  // Good - deterministic
profile.visualSignature.energy = ... plants.length ...  // Bad - random

// GOOD: Pure trait computation
function computeTraits(answers) {
  return Object.entries(answers).reduce((traits, [id, answer]) => {
    const dim = answer.dimension;
    if (!traits[dim]) traits[dim] = { values: [], depth: answer.depth };
    traits[dim].values.push(answer.trait);
    return traits;
  }, {});
}
```

### Problem 2: Weak USD Integration

**Current CLAUDE.md** already has USD Cognitive Substrate:
```usda
def "Profile" {
  custom string exploration = "Expansive"
  custom float exploration:score = 0.65
}
```

**The Translators outputs**: Markdown/JSON (no USD)

**The Opportunity**: The game should output USDA that MERGES with the cognitive substrate.

**USD Composition Semantics (LIVRPS)**:
- **L**ocal opinions (conversation context) — highest priority
- **I**nherit from parent prims
- **V**ariants for mode switching
- **R**eferences to external assets
- **P**ayloads for deferred loading
- **S**pecialize for inheritance

**The Translators profile as USD**:
```usda
def "TranslatorsProfile" (
  references = @/CognitiveSubstrate/Profile@
  doc = "Generated by The Translators — overwrites base profile"
)
{
  custom string pace = "Deliberate"
  custom float pace:score = 0.8
  custom string pace:behavior = "You appreciate context and thorough explanations"

  custom string exploration = "Expansive"
  custom float exploration:score = 0.75
  custom string exploration:behavior = "You enjoy exploring tangents and connections"
}
```

When merged via LIVRPS:
- TranslatorsProfile **references** base Profile
- Values **override** defaults
- System sees unified view

### Problem 3: Information Loss in Export Chain

**Current flow**:
```
Game → Markdown → Human copies → AI reads → AI interprets
         ↓              ↓              ↓
     Lossy format   Error-prone   Non-deterministic
```

**The thinkingmachines.ai insight**: Defeat non-determinism through:
1. **Fixed reduction order** — Same signals processed in same order
2. **Pre-processed layouts** — Anchors computed before inference
3. **Batch invariance** — Behavior independent of context size

**Apply to Translators**:

```javascript
// 1. Compute deterministic checksum from traits
const checksum = computeChecksum(traits);  // e.g., "TRL_abc123"

// 2. Generate anchor that AI can recognize
const anchor = `[TRANSLATORS:${checksum}]`;

// 3. Embed in output with semantic structure
const output = `
${anchor}

## Cognitive Profile

| Dimension | Value | Score |
|-----------|-------|-------|
| Pace | Deliberate | 0.80 |
...
`;
```

**AI sees anchor** → knows to apply profile with fixed priority

### Phase 2: USD Export

**Create**: `src/game/systems/USDExporter.js`

```javascript
/**
 * Export profile as Universal Scene Description
 * Compatible with CLAUDE.md Cognitive Substrate
 */
export class USDExporter {
  static toUSDA(profile) {
    return `#usda 1.0
(
  defaultPrim = "TranslatorsProfile"
  doc = "Cognitive profile from The Translators interview"
  customLayerData = {
    string generator = "The Translators v5"
    string checksum = "${profile.checksum}"
    string timestamp = "${new Date().toISOString()}"
  }
)

def "TranslatorsProfile" (
  references = @/CognitiveSubstrate/Profile@
  doc = "Behavioral preferences derived from interview responses"
)
{
${this.formatTraits(profile.traits)}

  # Insights derived from trait patterns
${this.formatInsights(profile.insights)}
}
`;
  }

  static formatTraits(traits) {
    return Object.entries(traits).map(([dim, trait]) => `
  custom string ${dim} = "${trait.label}"
  custom float ${dim}:score = ${trait.value.toFixed(2)}
  custom string ${dim}:behavior = "${this.getBehavior(dim, trait.value)}"`
    ).join('\n');
  }
}
```

### Phase 4: Update CalibrationState

**Modify**: CalibrationState.js `buildProfile()`

Separate deterministic computation from visual capture:
```javascript
buildProfile() {
  // 1. DETERMINISTIC: Compute traits from answers only
  const traits = DeterministicProfileEngine.computeTraits(this.answers);
  const insights = DeterministicProfileEngine.generateInsights(traits);
  const checksum = DeterministicProfileEngine.computeChecksum(traits);

  // 2. AESTHETIC: Visual signature (informational only, not used for AI)
  const visualSignature = {
    hue: this.colorHue,
    saturation: this.colorSaturation,
    brightness: this.brightness
    // Note: Garden metrics removed - they're random
  };

  return {
    traits,
    insights,
    checksum,
    visualSignature,
    raw: this.answers
  };
}
```

| LLM Problem | Translators Solution |
